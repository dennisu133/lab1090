# Oracle

Reference answers that lab1090 is checked against: what independent sources (another
decoder, weather balloons, a magnetic model) say, and the recording most of them are about.

## Where the files come from

| File            | What                                                                           | From                                                                                                  |
| --------------- | ------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------- |
| `capture.beast` | 10 min of real traffic (13 Nov 2026, 16:18:23 CET), 33,968 Mode S messages     | A readsb receiver's Beast output (RTL-SDR v3), saved byte for byte                                    |
| `pymodes/`      | Expected decodes of the capture's messages, and of synthetic ones it lacks     | [pyModeS](https://github.com/junzis/pyModeS), via `tools/oracle*.py`                                  |
| `sounding/`     | Two weather balloon ascents from Lindenberg (WMO 10393) bracketing the capture | Deutscher Wetterdienst, via the University of Wyoming's sounding archive (`tools/sounding.ts`)        |
| `wmm/`          | NOAA's 100 test values for the World Magnetic Model 2025                       | `WMM2025COF.zip` from [NOAA](https://www.ncei.noaa.gov/products/world-magnetic-model) (public domain) |

## Where these are used

By the tests (no Python or network needed) and a few tools, so moving or renaming a file
breaks them:

| File                                      | Used in                                                                                            |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------- |
| `capture.beast`                           | Most tests, through the `testing.ts` helpers; `tools/replay.ts`, `modulate.ts`, `dump-messages.ts` |
| `pymodes/crc.tsv`                         | `src/lib/modes/crc.test.ts`                                                                        |
| `pymodes/decoded.jsonl`                   | `identification`, `altitude`, `header`, `squitter` tests                                           |
| `pymodes/codes.json`                      | `src/lib/modes/altitude.test.ts`                                                                   |
| `pymodes/cpr.json`                        | `src/lib/modes/cpr.test.ts`                                                                        |
| `pymodes/commb.jsonl`                     | `src/lib/modes/registers.test.ts`                                                                  |
| `pymodes/synthetic.jsonl`, `surface.json` | `src/lib/modes/synthetic.test.ts`                                                                  |
| `sounding/`                               | `src/lib/weather/sounding.test.ts`                                                                 |
| `wmm/`                                    | `src/lib/weather/wmm.test.ts`                                                                      |

Don't edit the files by hand. `pymodes/` and `sounding/` are regenerated by tools
(`tools/README.md`) exactly as committed (`bun fmt` skips `pymodes/`), so a clean
`git status` afterwards means nothing changed.
